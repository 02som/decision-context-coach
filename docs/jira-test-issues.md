# AI 분석용 Jira 테스트 이슈

**관련 WBS ID:** 3.3

**담당자:** 박경서

**작성일:** 2026-11-26

**상태:** 완료 (PR 전)

**관련 Jira 작업:** DFAS-153

## 1. 목적

AI 분석·평가와 전처리(DFAS-152)를 시험할 Jira 테스트 이슈를 서로 다른 시나리오로 준비하고, 분석·평가 담당이 쓸 정규화 예시 데이터를 제공한다.

## 2. 요구사항 및 작업 범위

- 완료 기준 (WBS 3.3): 서로 다른 시나리오 3개
- API Contract v0.2.0 8절, MT2 요청 (DFAS-124 댓글): 테스트 이슈를 `{ key, summary, description }` 형태의 정규화 예시 데이터로 제공
- 범위 밖: 전처리 규칙과 R6 길이 측정(DFAS-152, `docs/jira-preprocessing.md`), AI 결과의 정확성 검증(DFAS-154)

## 3. 수행 내용

### 3.1 테스트 이슈

| 이슈 | 제목 | AI 분석 시나리오 | 전처리에서 확인할 것 |
|---|---|---|---|
| DFAS-156 | [테스트] 로그인 인증 방식 결정 | 결정과 대안이 명확히 적힌 이슈 | 서식 (R1~R5): 굵게, 하위 목록, 번호 목록, 표, 코드 블록, 링크 카드 |
| DFAS-157 | [테스트] 분석 결과 캐싱 방식 결정 | 결정이 긴 설명 끝에 묻힌 이슈 (원문 4,479자, 결정은 4,251자부터) | 긴 설명 자르기 (R6) |
| DFAS-158 | [테스트] README 오타 수정 | 설명이 없어 정보가 거의 없는 이슈 | 빈 설명 → `""` |

- DFAS-157 설명은 메모장에서 붙여 넣어 제목·목록 기호 없이 줄 단위 글만 남았다. 서식 확인은 DFAS-156이 맡는다

### 3.2 정규화 예시 데이터

1. 원본: `https://sominlee.atlassian.net/rest/api/3/issue/{이슈}?fields=summary,description` 응답 → `test/fixtures/jira/DFAS-15x.json`
2. 정규화: `toJiraContext`(DFAS-152)로 변환 → `test/fixtures/jira/DFAS-15x.normalized.json`

앱도 같은 주소로 조회하고 같은 함수로 변환하므로, 정규화 파일은 실제로 AI에 들어가는 내용과 같다.
